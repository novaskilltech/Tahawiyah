# العقيدة الطحاوية · قراءة وشرح

Projet pédagogique bilingue consacré au texte attribué à l’imam Abū Jaʿfar al-Ṭaḥāwī.

Le site proposera deux éditions séparées :

- arabe : texte contrôlé, explication simple et développée, glossaire, exercices et cartes ;
- français : texte arabe original, traduction française, explication simple et développée, glossaire, exercices et cartes.

Le projet est en cours d’édition. Aucune version publique ne sera publiée avant la revue intégrale du texte, des sources et des traductions.

## Sources de contrôle

- Édition contrôlée sur plusieurs manuscrits, présentée par IslamHouse.
- *Matn al-ʿAqīdah al-Ṭaḥāwiyyah*, al-Maktab al-Islāmī, répertorié par Usul.
- *Sharḥ al-ʿAqīdah al-Ṭaḥāwiyyah* d’Ibn Abī al-ʿIzz, utilisé comme une référence parmi d’autres pour l’explication.

Les références complètes et les éventuelles variantes significatives seront indiquées dans chaque unité concernée.
# Compteur de visites

La landing enregistre une visite locale par navigateur pendant la prévisualisation. Pour un compteur global en production Vercel, définir `KV_REST_API_URL` et `KV_REST_API_TOKEN` (endpoint Redis REST compatible Upstash), puis facultativement `VISITS_COUNTER_KEY`. La route `POST /api/visits` incrémente alors la valeur côté serveur sans exposer de secret au navigateur.
